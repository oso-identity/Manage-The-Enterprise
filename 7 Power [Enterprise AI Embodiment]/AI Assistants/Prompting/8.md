│   │   │   │   (Protects against: Ambiguous classifications, overlapping concepts, duplicated constructs,

│   │   │   │   │   provide information that is not already adequately represented elsewhere in the ontology?)
│   │   │   │   │   (Protects against: Duplicate concepts, information-equivalent constructs, unnecessary
│   │   │   │   │   synonyms, and multiple representations of the same underlying distinction)
│   │   │   │   │

│   │   │   │       where each construct applies?)
│   │   │   │       (Protects against: Ambiguous membership, category overlap, undefined transitions, and
