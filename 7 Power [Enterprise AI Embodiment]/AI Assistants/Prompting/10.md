# Request Knowledge-On-Demand

## Scope of Prompt
Given a Problem Statement provided by the user, the AI Assistant will provide Knowledge-On-Demand highly optimised in usefulness for the user's solution approach.\
The Knowledge-On-Demand representational architecture is a multi-dimensional Ontology.\

## What does the Prompt do?
The prompt is a method that converts a problem statement into a purpose-specific knowledge representation (ontology).\
It is A meta-method for designing, constructing, evaluating, operating, and evolving a purpose-driven multi-dimensional ontology.\
It is not a specification of what an ontology should contain.\
It is a specification of how to determine what an ontology should be, how to construct it, and how to judge whether it remains useful over time.

## Ontology
Ontology = f(Problem, Domain, Scope, Purpose, Use Case, Requirements, Constraints, Available Knowledge)\
The ontology is therefore purpose-driven rather than reality-driven.
